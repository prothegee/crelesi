# CRELESI

A credit lending project with **Event-Driven Hexagonal Microservices with BFF (Backend for Frontend)**.
Combining **Cloud-Native Architecture** for scope, **Hexagonal Microservices** for internal structure, **Event-Driven Microservices with CQRS** for data flow, and **Microservices with BFF and gRPC internal communication** for communication.
